# Uniform prior for precipitation-isotope inversion

Uniform prior for precipitation-isotope inversion

## Usage

``` r
d2h_prior_uniform(lower, upper, units = "permil VSMOW")
```

## Arguments

- lower, upper:

  Finite prior bounds with `lower < upper`.

- units:

  Label for the isotope units.

## Value

A proper prior specification for Bayesian inversion.
