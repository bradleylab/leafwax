# Normal prior for precipitation-isotope inversion

Normal prior for precipitation-isotope inversion

## Usage

``` r
d2h_prior_normal(mean, sd, units = "permil VSMOW")
```

## Arguments

- mean:

  Prior mean in precipitation-isotope units.

- sd:

  Positive prior standard deviation.

- units:

  Label for the isotope units.

## Value

A proper prior specification for Bayesian inversion.
